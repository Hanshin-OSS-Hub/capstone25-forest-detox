# 03. 도메인 용어 사전

## 문서 목적
이 문서는 프로젝트에서 사용하는 핵심 용어를 통일하기 위한 문서이다.  
화면 기획, Django 모델, API 명세, Flutter 변수명에서 같은 뜻의 용어를 일관되게 사용한다.

---

## 1. 사용자 관련 용어

### 사용자(User)
앱을 사용하는 일반 회원을 의미한다.

### 관리자(Admin)
Django 관리자 페이지에서 데이터를 조회하거나 관리하는 운영자를 의미한다.

### 로그인 제공자(Provider)
사용자가 어떤 소셜 로그인 수단으로 로그인했는지를 의미한다.

예:
- google
- kakao

### provider_uid
해당 로그인 제공자 안에서 사용자를 구분하는 고유 식별값이다.

---

## 2. 감정 관련 용어

### 감정 기록(Emotion Log)
사용자가 입력한 감정 데이터를 의미한다.  
텍스트 입력 또는 버튼 입력 모두 포함할 수 있다.

### 대표 감정(Primary Emotion of the Day)
특정 날짜를 대표하는 감정이다.  
현재 프로젝트에서는 해당 날짜의 **가장 최근 감정 입력값**을 의미한다.

### 원클릭 감정 버튼(Quick Emotion Button)
사용자가 한 번의 탭으로 감정을 입력할 수 있는 버튼이다.

기본값:
- 우울해
- 피곤해
- 즐거워
- 활기차
- 그저그래

### 감정 원문(Text Original)
사용자가 직접 입력한 감정 문장의 원본 텍스트이다.

### 감정 입력 방식(Input Type)
감정이 어떤 방식으로 입력되었는지를 의미한다.

예:
- text
- quick_button

---

## 3. AI 관련 용어

### AI 챗봇(AI Chatbot)
사용자의 감정 상태를 듣고, 위로 또는 코칭 문장을 제공하는 대화형 기능이다.

### 챗봇 세션(Chat Session)
한 번의 대화 흐름을 의미한다.  
필요 시 여러 메시지를 묶는 단위로 사용할 수 있다.

### 오늘의 팁(Today Tip)
사용자의 감정 상태 또는 일반적인 디지털 습관 개선을 위해 제공되는 짧은 조언 문구이다.

### AI 추천 목표(AI Suggested Goal)
AI가 사용자의 감정 또는 사용패턴을 바탕으로 추천한 목표를 의미한다.

---

## 4. 목표 및 챌린지 관련 용어

### 목표(Goal)
사용자가 달성해야 하는 행동 지침 또는 과제를 의미한다.

### 단기 목표(Short-term Goal)
하루 단위로 달성하는 목표를 의미한다.  
현재 프로젝트에서는 하루 3개 생성하는 것을 기본 정책으로 한다.

### 장기 목표(Long-term Goal)
월 단위로 달성하거나 유지하는 목표를 의미한다.  
현재 프로젝트에서는 매달 1일~말일 기준으로 3개를 운영한다.

### 챌린지(Challenge)
앱 내에서 사용자에게 제시되는 실행 과제를 의미한다.  
현재 프로젝트에서는 목표와 거의 같은 의미로 사용한다.

### 챌린지 상태(Challenge Status)
챌린지가 현재 어떤 상태인지 나타내는 값이다.

현재 단기 챌린지 기준 상태값:
- in_progress
- completed
- failed

failed 는 사용자가 직접 선택하는 상태가 아니라,
당일 자정이 지나도록 완료되지 않았을 때 서버가 자동으로 부여하는 상태이다.

### 난이도(Difficulty)
챌린지 수행 강도를 의미한다.

값:
- 초급
- 중급
- 고급

### 주간 난이도(Weekly Difficulty)
사용자가 이번 주에 선택한 기본 난이도이다.  
매주 월요일마다 새로 설정한다.

---

## 5. 사용시간 관련 용어

### 사용시간(Screen Time / Usage Time)
사용자가 휴대폰 또는 특정 앱을 사용한 시간을 의미한다.

### 일일 총 사용시간(Daily Total Usage Time)
특정 날짜 하루 동안의 총 휴대폰 사용시간이다.

### 앱 사용 기록(App Usage Log)
특정 앱의 사용시간 기록이다.

### 앱 Top5(Top 5 Most Used Apps)
특정 날짜에 가장 오래 사용한 앱 5개를 의미한다.  
현재 프로젝트에서는 Flutter가 Top5를 정리해 서버로 전송한다.

### 주간 목표시간(Weekly Usage Goal)
사용자가 일주일 기준으로 설정한 사용 목표시간이다.
현재 프로젝트에서는 분 단위 정수로 저장한다.
예:
- 4시간 = 240
- 3시간 30분 = 210

### 일일 목표시간(Daily Usage Goal)
주간 목표시간을 기준으로 계산되어 사용되는 하루 목표 사용시간이다.

### 진행률(Progress)
현재 사용시간이 목표시간 대비 어느 정도 진행되었는지를 나타내는 값이다.

---

## 6. 기록 탭 관련 용어

### 날짜별 기록(Daily Record)
특정 날짜에 대한 종합 데이터를 의미한다.

포함 예시:
- 대표 감정
- 총 사용시간
- 목표 달성 여부
- 당일 단기 목표 달성 현황
- 앱 Top5

### 캘린더 상세 조회(Calendar Detail View)
사용자가 기록 탭에서 날짜를 선택했을 때 표시되는 상세 정보 화면이다.

### 목표 달성일(Achievement Day)
해당 날짜의 목표를 성공적으로 지킨 날이다.

### 연속 달성일(Streak)
목표 달성일이 연속으로 이어진 일수이다.

---

## 7. 포인트 및 레벨 관련 용어

### 포인트(Point)
챌린지를 완료했을 때 사용자에게 지급되는 보상 수치이다.

### 단기 목표 포인트(Short Goal Point)
단기 목표 완료 시 지급되는 포인트이다.

현재 기준:
- 초급: 10P
- 중급: 20P
- 고급: 30P

### 단기 목표 재생성(Short Goal Regeneration)
사용자가 현재 날짜의 단기 목표를 새로 다시 생성하는 기능이다.
현재 프로젝트에서는 자동 재생성을 하지 않고, 사용자가 버튼을 눌러 재생성할 수 있다.
재생성은 하루 1회만 허용한다.

### 장기 목표 포인트(Long Goal Point)
장기 목표 완료 시 지급되는 포인트이다.

현재 기준:
- 초급: 100P
- 중급: 200P
- 고급: 300P

### 포인트 이력(Point History)
포인트가 언제, 왜, 얼마나 변동되었는지를 기록한 데이터이다.

### 누적 포인트(Total Point)
지금까지 획득한 총 포인트를 의미한다.

### 레벨(Level)
사용자의 성장 단계를 숫자로 표현한 값이다.

### 레벨업(Level Up)
누적 포인트가 특정 기준을 넘어서 다음 레벨로 상승하는 이벤트이다.

### 레벨 테이블(Level Table)
레벨별 필요 포인트를 정의한 기준표이다.  
현재 프로젝트는 레벨업 계산을 이 방식으로 처리한다.

---

## 8. 설정 관련 용어

### 알림 설정(Notification Setting)
사용자가 앱 알림 수신 여부를 조절하는 설정이다.

### 푸시 알림(Push Notification)
일반 알림 또는 챌린지 관련 알림을 의미한다.

### 사용시간 알림(Usage Alert)
사용시간이 목표를 초과했을 때 보내는 알림을 의미한다.

### 야간 리마인더(Night Reminder)
취침 전 디지털 사용을 줄이도록 안내하는 알림이다.

### 로그아웃(Logout)
앱 사용을 종료하고 인증 상태를 해제하는 동작이다.  
현재 프로젝트에서는 Django와 Firebase 양쪽 모두를 정리한다.

---

## 9. 데이터 정책 관련 용어

### SQLite
현재 프로젝트에서 사용하는 데이터베이스 엔진이다.

### Django ORM
Django에서 모델을 통해 데이터베이스를 다루는 방식이다.  
현재 프로젝트는 SQLite를 사용하므로 ORM 중심 개발을 원칙으로 한다.

### API Endpoint
Flutter가 호출하는 Django 서버의 URL 경로를 의미한다.

예:
- /api/accounts/
- /api/usage/
- /api/wellness/

### JSON 응답(Response JSON)
서버가 Flutter에 반환하는 데이터 형식이다.

---

## 10. 현재 프로젝트의 앱 용어 정리

### accounts 앱
사용자, 인증, 로그인 제공자, 프로필 관련 기능을 담당하는 앱이다.

### usage 앱
사용시간, 앱 사용 기록, 통계성 데이터 관련 기능을 담당하는 앱이다.

### wellness 앱
감정 기록, AI 코칭, 목표/챌린지 로직 등 사용자 웰빙 관련 기능을 담당하는 앱이다.

### backend 폴더
Django 프로젝트 전역 설정과 URL 라우팅을 담당하는 폴더이다.

---

## 11. 용어 사용 원칙

1. 문서, 모델, API, 화면에서 같은 개념은 같은 이름을 사용한다.
2. 사용자 화면 표현과 개발용 내부 이름이 다를 경우 문서에 따로 기록한다.
3. 감정, 목표, 챌린지, 포인트, 레벨 용어는 혼용하지 않는다.
4. 현재 프로젝트는 SQLite 기준으로 개발한다.
5. SQLite를 사용하더라도 Django ORM 중심으로 작성한다.
